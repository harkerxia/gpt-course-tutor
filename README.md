# Course Tutor

An adaptive GPT tutoring plugin that helps you understand course materials through step-by-step explanations and interactive guidance.

## Features

- **Adaptive explanations:** Adjusts the depth and pace of explanations based on what you already understand.
- **Step-by-step learning:** Breaks complex concepts into manageable stages.
- **Answer-first support:** Gives a direct answer to a specific question, then explains the reasoning.
- **Interactive Q&A:** Responds to follow-up questions and clarifies confusing concepts.
- **Organized learning:** Helps work through multiple questions without losing the learning path.

## Installation

1. Open the [Course Tutor v1.0.0 release](https://github.com/harkerxia/gpt-course-tutor/releases/tag/v1.0.0).
2. Under **Assets**, download the plugin package (not GitHub's automatically generated source-code archive).
3. Drag and drop the downloaded plugin package into **ChatGPT**, then follow the installation prompts.
4. Once installed, invoke it with `@tutor`.

## Usage

Share your lecture notes, slides, readings, or questions in ChatGPT. Mention `@tutor` to start a tutoring session.

For example:

```text
@tutor Teach me this material step by step.
```

```text
@tutor Answer this problem first, then explain the reasoning.
```

```text
@tutor Help me work through my questions in order.
```

Course Tutor uses the materials and conversation context you provide to guide the explanation, check what needs clarification, and adapt as you learn.
